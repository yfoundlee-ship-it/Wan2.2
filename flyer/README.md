# Animated 10-second flyer

A 10 s, 1080×1920 (9:16) animated event flyer — **`event-flyer.mp4`** — built entirely
from code. Everything on screen (background, type, stickers, confetti, ribbon, sound)
is generated procedurally: no stock assets, no GUI, no paid tools.

![flyer](stills/flyer-9.6s.jpg)

## Deliverables

| file | what it is |
| --- | --- |
| `event-flyer.mp4` | the flyer — 1080×1920, 30 fps, 10.0 s, H.264 + AAC stereo, ~10 MB, `+faststart` |
| `event-flyer.wav` | the 10 s music bed on its own (44.1 kHz stereo) |
| `event-flyer-poster.png` | still poster frame (9.4 s) for feed posts |
| `stills/` | key frames pulled from the finished video |
| `render_flyer.py` | the animation renderer (Pillow + numpy → ffmpeg) |
| `make_audio.py` | the music synthesiser (numpy) |
| `content.json` | **all the copy and the palette — edit this** |

## Storyboard

| t | beat |
| --- | --- |
| 0.0–1.0 s | gradient + drifting light blobs; badge badge-in and yellow star pop |
| 1.1–2.2 s | title types in letter-by-letter — spring overshoot, 3D extrusion, white pop flash |
| 2.9 s | tagline rule slides in |
| 3.2 s | **beat drop** — date sticker slams down, confetti bursts, crash cymbal |
| 3.5–4.0 s | venue, city, doors |
| 4.6 s | marquee ribbon wipes in and scrolls forever |
| 5.2 s | CTA button springs in, keeps breathing until the end |
| 6.4–10 s | slow camera push-in, light sweep, sparkles, end card |

Audio is a 96 BPM Am–F–C–G bed whose hits are cut to those same beats.

## Change the details

Open `content.json`, swap the strings, re-render. Long titles auto-shrink to fit,
and the ribbon re-tiles itself from the `marquee` list.

```json
{
  "badge": "LIVE · ONE NIGHT ONLY",
  "title": ["EVENT", "NAME"],
  "tagline": "FOOD · MUSIC · MARKET",
  "date": "SAT 24 OCT",
  "doors": "DOORS 20:00",
  "venue": "THE WAREHOUSE",
  "city": "JOHANNESBURG",
  "cta": "FREE ENTRY · RSVP @YOURHANDLE",
  "marquee": ["#EVENTNAME", "ONE NIGHT ONLY", "BRING THE CREW"],
  "footer": "PLACEHOLDER COPY — SWAP IN YOUR OWN DETAILS"
}
```

Also editable in the same file: `badge`, `title` (up to 2 lines), `tagline`, `date`,
`doors`, `venue`, `city`, `cta`, `marquee`, `footer`, and `palette` — `bg_top`,
`bg_mid`, `bg_bot`, `accent`, `accent2`, `ink`. Recolour the whole flyer by changing
those seven hex-ish RGB triples.

## Re-render

```bash
./setup.sh                      # once: venv + pillow/numpy + ffmpeg binary
./.venv/bin/python make_audio.py
./.venv/bin/python render_flyer.py            # -> event-flyer.mp4 (video only, ~2.5 min)

# mux the soundtrack on
ffmpeg -i event-flyer.mp4 -i event-flyer.wav -c:v copy -c:a aac -b:a 192k \
       -shortest -movflags +faststart out.mp4
```

Options:

```bash
render_flyer.py --ss 3 --crf 16          # higher quality, ~3x slower
render_flyer.py --jobs 1                 # single process (low-RAM machines)
render_flyer.py --preview 3.2 5.2 9.6    # just those timestamps -> stills/*.jpg
```

Other formats are a one-line change: set `W, H = 1080, 1080` (square) or `1920, 1080`
(landscape) at the top of `render_flyer.py`. The layout grid below it
(`LINE1_Y … FOOTER_Y`) is in the same coordinate space, so nudge those numbers if you
switch aspect ratio.

## How it works

* **Frames** — Pillow + numpy draw straight into a 2160×3840 supersampled canvas that is
  box-filtered down to 1080×1920, then piped to ffmpeg as raw `rgb24` (no PNG round-trip).
* **Background** — a 3-stop gradient computed at 270×480 and upscaled, with six additive
  coloured light blobs, so the whole field drifts with time almost for free.
* **Type** — each glyph is rasterised once, then positioned/scaled/rotated per frame with
  a spring curve, plus stacked flat copies for the 3D extrusion.
* **Post** — quarter-res bloom, a light sweep, vignette and film grain, all in numpy.
* **Parallelism** — frames are independent, so a `spawn` pool renders across cores.
* **Audio** — numpy drum/pluck/pad synthesis with a short FFT reverb and a soft-knee limiter.

## Requirements & licence notes

Python 3.9+, `pillow`, `numpy`, and an `ffmpeg` binary. `setup.sh` installs the first two
into `.venv` and drops a static ffmpeg into `.tools/` if the system has none.

Fonts: **Poppins** (SIL Open Font License 1.1 — see `fonts/OFL.txt`). Everything else
here is generated by these two scripts.
